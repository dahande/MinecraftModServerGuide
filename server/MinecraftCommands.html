💡 これらは サーバー側のデータパック で提供されているカスタムコマンドです。すべて /trigger で実行します。 MOD導入は不要、バニラクライアントから入力できます。
カテゴリ コマンド 説明 / 使い方 例
🪓 一括破壊 /trigger TimberToggle 木の一括伐採のオン/オフを切替。オン時に斧で原木を壊すと、繋がっている木全体を一気に伐採できます。 /trigger TimberToggle
📍 座標表示 /trigger ch_toggle アクションバーへの座標表示のオン/オフを切替。常に X / Y / Z を確認できます。 /trigger ch_toggle
🏠 チェックポイント /trigger sethome add <n> 現在地をチェックポイントスロット n に登録 (n は任意の番号、例: 1〜9)。 /trigger sethome add 1
🏠 チェックポイント /trigger home set <n> 登録済みのチェックポイントスロット n に瞬間移動。 /trigger home set 1

📝 使い方ヒント

  • /trigger はバニラ Minecraft の組み込みコマンドです。datapack側で許可された範囲だけ実行できます。
  • チェックポイントは番号 (1〜9 程度) を変えれば複数登録できます。家・ネザー出口・ビレッジ等を分けて登録すると便利。
  • 機能のオン/オフはプレイヤー単位で記憶されます。あなたが ON にしても他の人には影響しません。
  • うまく動かないときは /trigger TimberToggle のように引数なしで打つと「現在の状態」が表示されます (機能による)。
